Reused

The group header with a trailing meta slot is the existing GroupHeader. The provenance strip reuses ValidationCard's badge row (small mono chips on bg-raised, timestamp pushed right) so a captured output reads as a sibling of a validation result. Pending is the same dashed ghost box as the empty schema.

New

A collapsible JSON tree — CC renders JSON today only as a <pre> inside markdown, which can't be folded. Colour is deliberately thin: keys secondary, strings primary, numbers amber, booleans cyan, punctuation tertiary — no full syntax palette, because the value is short and structured, not code to read. Also new: the repair chip is omitted when no repair ran, so its presence is the signal.

Suggested primitive

ui/JsonTree (value + defaultCollapsedDepth + copy). Immediate second and third consumers: the halt dialog's raw failure payloads and boundInputs in the overview, both currently flat text.

Friction

CopyableId exists but is built for a single-line identifier — it can't carry a multi-line payload, so the copy action here is a plain Button size="sm" with its own copied-confirmation state. And CC has no "provenance" chip vocabulary: fenced deserves a mild "worth noticing" tone, but the only warm tone is amber (reserved for awaiting) — it is used here anyway, which is a deliberate small stretch the spec should ratify or reject.
