Reused

Lives inside the existing data-section="header" Brief group as a fourth identity field, using the same label-row + inline-action layout as description and acceptance criteria, and the same hint line beneath. Save routes through the existing header Save button and the store's updateExecutionContext path — outputSchema is just another key in the Partial<…ContextDefinition> patch.

New

A Schema chip in the resolved-setup strip — the strip already answers "what will this context do", and declaring a contract belongs in that answer. It uses the neutral GateChip recipe (not a backend colour) since no agent owns it. Also new: clearing names its blast radius ("2 downstream contexts lose this input"), which no other identity field needs.

Friction

Every other structured editor in this panel is an InspectorConfigBlock, so a bare field at this visual weight reads slightly light beside them — the Brief group's own rhythm carries it, but reviewers will ask. Second: contextOverrideCount counts cascade sources; the schema must be excluded from it or the "1 override" readout becomes wrong. Third: acceptance criteria gets a focus sheet (InspectorFocusSheet) for long content — a 40-line schema wants the same, but the sheet is Markdown-shaped and would need a monospace/no-render mode.
