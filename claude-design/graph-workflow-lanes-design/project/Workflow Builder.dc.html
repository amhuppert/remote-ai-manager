An empty lane is draft UI state. It is not an authored entity, it is never serialized, and creating it does not make the definition dirty — the toolbar still says All changes saved. It disappears on Reset, reload, workflow switch and Save. Dropping a context into it changes that context's placement.lane; that is the edit, and that is what Save persists. Moving the last context out removes the lane again.

Naming it delivery means “use the existing lane” — the band merges with it rather than creating a duplicate. Names go through the existing lane-name validation; session and __session__ are refused.

Layout versus semantics. Moving a node inside its own lane writes visual layout only. The lane boundary is the only thing that turns a drag into a semantic edit, and the only field it writes is placement.lane. Grade, owned paths and everything else are carried across verbatim — there is no silent re-grading.

Validation runs before acceptance. The post-drop draft goes through the same placement validation the CLI and the save path use: lane-name grammar, reserved-lane rules, the read-only output contract, and same-lane concurrency. A failure refuses the drop with the concrete reason and the remedy.

Concurrency is explained where it bites. Dropping a second full member onto an occupied lane is legal but tells you it will wait for exclusive occupancy; two owned members with overlapping paths are refused with the overlap named.

Selection. Clicking a node selects it and switches the rail to Context scope; clicking empty canvas deselects and returns to Workflow scope. The scope tabs stay usable in both states, so the workflow defaults are one click away while a context is selected. Dependency edges are drawn port-to-port; a selected node or edge is removed with Delete or from its context menu.
