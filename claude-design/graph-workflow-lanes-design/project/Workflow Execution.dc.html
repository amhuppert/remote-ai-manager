Why four modes and not a disabled flag. The classifier answers two questions — is the execution editable, and what is this context's lifecycle. Editable needs both: an unstarted context, or a started one while the run is quiescent. Everything else has a different sentence and a different way out, so the surface says which one applies rather than greying the fields out silently.

Snapshot, not re-resolution. A running execution works from its snapshotted configuration. An accepted live edit affects subsequent work; it is not re-resolved from Global or Workflow at an iteration boundary, and editing the saved template never reaches the run.

No Workflow scope here. The live surface is context-oriented, so the scope switch does not appear. Workflow-level live changes — lane-merge validation, charter amendment — are separate existing behaviour and are not this panel.
