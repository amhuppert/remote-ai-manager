06 Behavior

Anchor & reposition

The menu opens at the cursor's clientX, clientY. After mount, if it would overflow the viewport, it slides left/up by the overflow amount with an 8px gutter from the window edge. It never repositions while open.

Dismissal

Closes on outside mousedown, on Esc, or after any item is selected. Selecting an item invokes its onSelect handler before closing.

Disabled items

Pin as tab re-labels to Already a tab when this conversation is already pinned, or Tab limit reached (6) at cap. Both render with the disabled state and are non-clickable but still focusable for screen-reader announcement.

Copy context payload

Writes a single markdown block: H1 title, then a metadata table (project, session, branch, target branch, status, current tool, last active), then a horizontal rule, then every message in order — author label and body, untruncated. Toast confirms with "Context copied."

Archive distinction

Archive conversation takes a single thread out of the sidebar and leaves the worktree intact. Archive session archives every conversation tied to the session and shuts the worktree down — it warrants a confirm dialog whose body reads "This archives all conversations on this session and removes the worktree."

Accessibility

Container is role="menu"; items are role="menuitem" rendered as native <button>. Focus moves to the first item on open; ↑ ↓ navigate, ↵ activates, Esc closes. Hotkey glyphs are aria-hidden — the accessible name is the label alone.
